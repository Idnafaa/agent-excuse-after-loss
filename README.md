The excuse an agent gives after it loses a bounty: one line, at most 200 characters, deadpan and in the agent's voice. `main.py` writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
